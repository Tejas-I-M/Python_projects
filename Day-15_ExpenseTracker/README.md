# Day 15 - Expense Tracker

## Concepts Used

* Encapsulation
* Abstraction
* File Handling (JSON)
* State Persistence
* Data Aggregation

## Features

* Add expenses
* View all expenses
* Calculate total spending
* Persistent storage using JSON

## Description

This project is a simple expense tracker that allows users to record and manage their daily expenses. Data is stored in a JSON file to maintain persistence across sessions.

## Learning Outcome

* Learned how to manage real-world financial data
* Practiced file handling and persistence
* Built a complete CLI application
* Applied OOP design to a practical use case
